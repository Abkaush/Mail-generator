# 📧 Cold Email Generator (WIP)

> ⚠️ **Status:** Work in Progress. Basic UI and chain logic implemented.

## Overview
An AI-powered tool built with Streamlit, LangChain, and Groq LLM to scrape job postings and auto-generate targeted cold emails.

## Tech Stack
- Streamlit
- LangChain / LangChain-Groq
- ChromaDB (Vector Store)
- Python
